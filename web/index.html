予約を取り込む

お持ちの予約情報をそのまま使えます。手入力は最後の手段です。

📧 予約確認メールを貼り付け
予約サイトからの確認メール本文を貼るだけ。店名・日時・場所・金額・キャンセル規定を AI が読み取り、確認してから登録します。
📅 カレンダーから取り込み（.ics）
Google カレンダーや TimeTree からエクスポートした .ics ファイルを選ぶと、今後の予定をまとめて登録します。
📷 スクショ・写真から読み取り
予約画面やカレンダー画面のスクリーンショットを AI（vision）が読み取り、確認してから登録します。
🔄 カレンダーと自動連携（逆方向）
取り込みではなく出力：確定した予約を Google カレンダーや iPhone のカレンダーに自動で表示します。設定は1回だけ。
✎ 手動でまとめて入力する（最後の手段）

予約確認メールを貼り付け

確認メールの本文を貼り付けてください。電話番号・メールアドレスは送信前に自動でマスクされます。

‹ 戻るカレンダーから取り込み

スマホからは .ics ファイルを書き出せないアプリが多いので、スクショ読み取りが一番早いです。予定の一覧が写った画面を撮って選ぶだけで登録できます。

  • 🌳 TimeTree: スマホから .ics を書き出す方法はありません。スクショで取り込みます。
  • 🍏 iPhone のカレンダー: 同じくスクショが確実です。
  • 📗 Google カレンダー: .ics の書き出しはパソコンのブラウザだけです。

カレンダーの「.ics ファイル」を選ぶと、今後の予定をまとめて取り込めます（候補・キャンセル料「不明」で登録され、あとから編集できます）。

パソコンで .ics ファイルを取り出す手順（アプリ別）
📗 Google カレンダー（PC ブラウザ）
  1. 歯車 → 「設定」 → 左の「インポート / エクスポート」
  2. 「エクスポート」を押すと zip がダウンロードされる
  3. zip を開いて中の .ics ファイルをここで選ぶ
🌳 TimeTree
  1. 手軽なのはスクショ読み取り（下のボタン）。予定一覧が写った画面を撮るだけ
  2. まとめて全部移すなら、PC で無料公開ツール「timetree-exporter」を使うと .ics を書き出せます（公式のエクスポート機能は無いため）
  3. ツールに TimeTree のパスワードを入力するので、実行前に仮のパスワードへ変更 → 終わったら戻すと安心です
🍏 iPhone のカレンダー
  1. .ics の書き出しが難しいのでスクショ読み取りが手軽です（下のボタン）

連携と通知

① 締切のお知らせを LINE で受け取る

無料キャンセルの期限が近づくと、plancel の公式アカウントから LINE でお知らせが届きます。連携するとあなたあてのお知らせは、あなたの LINE に届きます。台帳を共有している方も、それぞれご自分の LINE で受け取れます。

1. plancel を友だち追加する
💬 LINE で友だち追加
LINE ID は @791wbdma（ID をコピー）。パソコンで見ているときは、スマホの LINE で ID を検索するか、このページをスマホで開いて上のボタンを押してください。
2. このアカウントと連携する

友だち追加が済んだら、コードを発行して LINE のトークに送ってください。トークに送ったコードで、この plancel アカウントとつながります。

  1. ①コードをコピー
  2. ②LINE の plancel トークに送る
  3. ③下の「連携を確認」を押す
もう一度発行すると、前のコードは使えなくなります。
